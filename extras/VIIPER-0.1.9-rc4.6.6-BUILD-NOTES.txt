Behavioral scope:

Startup now propagates cancellation through prerequisite checks, reports the
failing startup phase, and retires its owned listeners and accepted API clients.
Packaged tray startup is managed by DS4Windows; the old bare-server autostart
toggle requires the existing explicit developer-only opt-in. Existing user
startup entries are not rewritten by the broker. Built-in self-updating remains
disabled; DS4Windows installs and repairs this exact matching payload.

Edge descriptors and feature sizing now distinguish the model correctly.
Common native game feedback retains the 48-byte V5 prefix and independent PCM
lane. Unsupported Edge configuration and onboard-profile commands are rejected
transactionally instead of partially applied or falsely acknowledged. Virtual
gyro calibration now matches the client's canonical 16-unit motion scale.
Neither onboard-profile storage nor complete physical Edge hardware validation
is claimed. See docs/devices/dualsense.md in the matching source.

Existing Sony Bluetooth WDL conversion and ISO-OUT clock behavior remain; the
application now negotiates that converter for either Sony model pairing.
Nintendo and legacy target conversion are unchanged by this broker release.
The complete GPL, Apache systray and altered WDL notices remain included.
No private capture/trace recorder or speculative physical configuration writes
are included. Automated tests do not prove identical effects in every game.
